# Booking Telegram Bot

Демонстрационный Telegram-бот для записи клиентов на услуги.

Планируемый сценарий:

1. Клиент запускает бота.
2. Выбирает услугу и мастера.
3. Выбирает дату и свободное время.
4. Оставляет номер телефона.
5. Владелец получает уведомление, а запись сохраняется.

## Текущий этап

Готов полный демонстрационный путь записи: услуга, мастер, дата, время, телефон
и подтверждение. Также работают контакты и раздел записей. Следующие этапы:
сохранение записей в базе и уведомление администратора.

## Запуск

1. Создать файл `.env` по образцу `.env.example`.
2. Указать токен Telegram-бота в `BOT_TOKEN`.
3. Установить зависимости: `py -m pip install -e .`
4. Проверить подключение: `py check_bot.py`
5. Запустить: `py main.py`

## Бесплатное размещение на Render

Файл `render.yaml` описывает готовый бесплатный веб-сервис. В облаке бот
работает через защищённый Telegram webhook, а токен хранится в секретной
переменной `BOT_TOKEN` и не попадает в репозиторий.

Бесплатный сервис может засыпать при отсутствии сообщений. Первое сообщение
после паузы иногда обрабатывается с задержкой.
